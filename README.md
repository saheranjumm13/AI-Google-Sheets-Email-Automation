# AI-Google-Sheets-Email-Automation
AI-powered n8n workflow for analyzing Google Sheets data and automatically sending reports through Gmail.

AI-Powered Google Sheets Data Analysis & Email Automation

📌 Overview

  This project is an AI-powered automation workflow built using n8n.
  
  The workflow reads data from Google Sheets, analyzes the data using an AI Agent, and automatically sends the analysis report to Gmail.
  
🔄 Workflow

  Google Sheets
  ↓
  n8n AI Agent
  ↓
  Data Analysis
  ↓
  Gmail
  ↓
  Automated Report

🚀 Features

  - Reads data from Google Sheets
  - Uses an AI Agent for data analysis
  - Identifies unique customers
  - Groups customers by city
  - Calculates useful data summaries
  - Generates an HTML email report
  - Automatically sends the report through Gmail

🛠️ Technologies Used

  - n8n
  - Google Sheets
  - Google Gmail
  - AI Agent
  - OpenAI Chat Model
  - Simple Memory

 📊 Example Analysis

  The workflow can answer questions such as:

  - How many rows are in the spreadsheet?
  - How many unique customers are there?
  - Which customers belong to each city?
  - What insights can be obtained from the data?
  - Can the analysis be sent automatically by email?
